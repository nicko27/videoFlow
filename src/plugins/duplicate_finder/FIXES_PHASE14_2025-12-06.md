### Parameter Recommendations

#### Similarity Threshold

```
95-100% : Quasi-identical duplicates only
85-94%  : Recommended ⭐ (detects light compression)
75-84%  : Detects crops and modifications
< 75%   : High false positive risk
```

**By use case**:
- Exact duplicates: 95%
- General use: 85% ⭐ (recommended)
- Modified videos: 75%

#### Workers Configuration

**Formula**:
```python
Hash Workers = CPU_CORES
Comparison Workers = CPU_CORES * 2

# Examples:
# 4 cores → 4 hash, 8 comparison
# 8 cores → 8 hash, 16 comparison
```

**If limited RAM** (< 8 GB):
```python
Hash Workers = 2
Comparison Workers = 4
```

### Troubleshooting Examples

#### Problem: "No duplicates found"

**Solutions**:
1. Lower threshold to 75%
2. Try Audio-First mode (threshold 0.50)
3. Manually verify videos are similar
4. Enable debug logs

#### Problem: "Analysis is slow"

**Solutions**:
1. Use Audio-First mode (10x faster)
2. Reduce workers if low RAM
3. Increase workers if CPU available
4. Enable "Early Exit" optimization
5. Reduce frame count (30 → 20)

### FAQ Highlights

**Q: Can I recover deleted files?**

A: Yes! Files are moved to system trash, not permanently deleted.
- macOS: Finder → Trash
- Linux: Files → Trash
- Windows: Recycle Bin

**Q: Supported video formats?**

A: All FFmpeg-supported formats:
- ✅ MP4, AVI, MKV, MOV, WMV, FLV, WEBM
- ✅ ProRes, DNxHD, AVCHD
- ✅ MPEG, VOB, 3GP, ASF

**Q: How much cache space is needed?**

A: Approximately:
```
Per video:
- Hash: ~10 KB
- Audio fingerprint: ~50 KB
- Extracted frames: ~500 KB

For 1000 videos:
- Total: ~560 MB
```
