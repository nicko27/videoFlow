### 5. Data Flow Diagrams

**4 Complete Data Flows**:

#### File Addition Flow
```
User selects files
    → FileHandler.add_files()
    → FileValidator.validate_paths_batch() [Phase 10]
        ├─► Path resolution
        ├─► Traversal check
        ├─► Symlink check
        ├─► Extension check
        ├─► Size check
        └─► Return (valid, invalid)
    → Filter existing
    → FileListWidget.add_files()
    → Display in UI
```

#### Hash Computation Flow
```
AnalysisHandler.start_hash_computation()
    → HashWorker (QThread)
    → For each file:
        → DatabaseManager.check_cache()
        → VideoHasher.compute_video_hash()
            → FrameCache.get() [Phase 7]
            → Extract frames
            → FrameCache.set()
            → Compute hash
            → DatabaseManager.store_hash()
    → Progress updates → UI
```

#### Comparison Flow (Normal)
```
AnalysisHandler.start_comparison()
    → ComparisonWorker
    → Generate N² pairs
    → For each pair:
        → is_pair_ignored()?
        → get_cached_comparison()?
        → compare_hashes()
        → store_comparison()
    → Return duplicates
```

#### Audio-First Workflow
```
AnalysisHandler.start_audio_first()
    → AudioWorker
        → Extract MFCC
        → LSH indexing
        → Query candidates (e.g., 10 out of 4950)
    → ComparisonWorker (specific_pairs only) [Phase 1 Fix]
        → Compare ONLY 10 pairs (not 4950!)
    → Return audio-verified duplicates
```

**Value**: Understand exactly how data flows through the system

### 8. Design Patterns

**5 Key Patterns Documented**:

#### 1. Worker Pattern (QThread)
```python
class HashWorker(QThread):
    progress_updated = pyqtSignal(int)
    finished = pyqtSignal(dict)

    def run(self):
        # Heavy computation in background
```

**Benefits**: Responsive UI, parallel processing, progress updates

#### 2. Connection Pool Pattern
```python
class ConnectionPool:
    def __init__(self, db_path, pool_size=None):
        # Auto-size based on CPU count
        self.pool_size = min(cpu_count + 2, 10)
```

**Benefits**: Connection reuse, thread-safe, optimal sizing

#### 3. LRU Cache Pattern
```python
class FrameCache:
    def get(self, video_path, num_frames, mtime):
```

**Benefits**: 10-100x speedup (Phase 7)

#### 4. Strategy Pattern
```python
def compute_hash(self, frame, method=HashMethod.PHASH):
    if method == HashMethod.PHASH:
        return self._compute_phash(frame)
```

**Benefits**: Algorithm flexibility
