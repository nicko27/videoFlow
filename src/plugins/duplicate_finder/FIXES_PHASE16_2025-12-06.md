### 6. Contribution Workflow

**7-Step Process**:

1. **Fork and Clone**
   ```bash
   git clone https://github.com/YOUR_USERNAME/videoFlow.git
   ```

2. **Create Branch**
   ```bash
   git checkout -b feature/add-new-algorithm
   ```

3. **Make Changes**
   - Write clean code
   - Follow standards
   - Add tests
   - Update docs

4. **Test Changes**
   ```bash
   pytest
   black .
   flake8 .
   ```

5. **Commit**
   ```bash
   git commit -m "feat: Add new LSH algorithm

   - Implement MinHash LSH
   - Add tests
   - Update documentation

   Fixes #123"
   ```

6. **Push and Create PR**
   ```bash
   git push origin feature/add-new-algorithm
   ```

7. **Code Review**
   - Address comments
   - Update PR
   - Be responsive
